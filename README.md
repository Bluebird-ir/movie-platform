# 🎬 CineVault – Movie Platform

A stylish movie discovery web app where users can browse popular films, search by title, save favorites, and keep personal notes in a journal. 😍
This was a group project in our WBS Coding School Software Engineering Program. 🎓
---

## 😊 What We Built

This project is a front-end movie platform built with vanilla JavaScript and TailwindCSS styling.

- 🔥 Fetched **popular movies** from the TMDB API
- 🔎 Added a **search modal** to find movies by name
- ❤️ Added a **favorite system** using `localStorage`
- 📔 Built a **Journal page** for saved movies
- ✍️ Added **note-taking per movie** (with add and delete note actions)
- 🎨 Designed a modern dark UI with custom colors, gradients, and responsive card layout

## 🧩 What’s Included

- `index.html` – main page with popular movies and search
- `main.js` – API fetching, movie rendering, search logic, favorite handling
- `journal.html` – favorites journal page
- `journal.js` – journal rendering, notes feature, remove-from-favorites logic
- `tailwind.config.js` – custom theme colors and fonts
- `simulate-api.js` – API key/token placeholders and helper fetch functions

---

## 🛠️ Tech Stack

- HTML5
- JavaScript (ES Modules)
- TailwindCSS (CDN + config)
- TMDB API
- Browser `localStorage`

---

## 💡 Main Features in Action

- On load, the app shows trending/popular movies 🎥
- Users can click the search button to open a modal and search quickly ⚡
- Clicking the heart icon saves/removes a movie from favorites ❤️
- Favorites appear in `journal.html` automatically
- Users can write personal notes for each saved movie 📝
